🦆 小黄鸭乐园 · 家长指南

目标：用小黄鸭动画吸引宝宝注意，鼓励宝宝开口模仿发音和词语（嘎嘎、爸爸、妈妈、你好、一 二 三……）。鸭鸭说出词后，请带宝宝跟读；宝宝一有反应就会收到「宝宝真棒！」的庆祝。
  • 点屏幕：点水里会跳出小鸭鸭，点天上会飞过小鸭鸭；点泡泡会「啵」地破掉并读出里面的词
  • 键盘任意键都有反应：小鸭鸭会带着一个词出现
  • 空格＝大鸭鸭嘎嘎　D＝数鸭鸭（一二三四五）　B＝泡泡　M＝唱歌　N＝白天/夜晚　回车＝全部跳起来　方向键＝冲刺/跳跃/从天而降　数字 1-5＝变出对应数量的小鸭鸭
  • 🎤 麦克风：开启后，听到宝宝发声会自动庆祝（声音只在本地分析，不存储、不上传；http://localhost 或 https 下可用）
  • 🔊 静音　⛶ 全屏更适合平板
  • 建议家长全程陪同：跟着一起说、一起拍手、夸张地表扬，比宝宝单独看屏幕效果好得多
