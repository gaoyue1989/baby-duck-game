# 🐥 小黄鸭乐园

一个面向 **2 周岁左右宝宝** 的小黄鸭主题互动网页游戏：满屏大号小黄鸭动画 + 声音 + 词语朗读，触摸或键盘触发，吸引宝宝开口模仿说话。

- **单文件、零依赖、离线可用**：只有一个 `index.html`，双击即可玩
- **宝宝不需要识字**：气泡里全是图画（🐥👶🌸👏），词语靠真人语速的中文朗读（系统 TTS）和鸭叫音效传达；唯一的文字是顶部给**家长**看的引导条
- 画面全部用 SVG/CSS 绘制，音效用 WebAudio 本地合成，**不联网、无广告、无追踪**
- 麦克风功能（可选）：宝宝一发声就庆祝，声音只在本地分析，**不存储、不上传**

## 快速开始

**macOS 客户端(推荐)**:`clients/macos/build.sh` 编译好的独立 App 在 `dist/BabyDuck.app`,双击即玩,窗口可全屏。重新编译:

```sh
cd clients && ./gen-icons.sh && ./sync.sh && ./macos/build.sh
```

**电脑浏览器**:直接双击 `index.html`(推荐 Chrome / Edge / Safari)。

**Android / iOS 原生版**:完整工程在 `clients/android/`(Android Studio 直接打开)和 `clients/ios/BabyDuck.xcodeproj`(Xcode 16+ 直接打开),详见 [clients/README.md](clients/README.md)。三个客户端都是同一个 WebView 壳加载同一份 `index.html`,并用系统中文语音朗读词语;改了游戏代码后运行 `clients/sync.sh` 同步进各工程。

**平板 / 手机(网页方式)**:电脑上在该目录运行

```sh
python3 -m http.server 8000
```

然后手机浏览器打开 `http://电脑IP:8000`(同一 Wi-Fi 下;iPhone 可在 Safari 打开后「添加到主屏幕」当 App 用)。游戏本身任何方式都能玩;只有 🎤 麦克风功能要求 `localhost` 或 `https` 环境。

## 玩法（家长先看）

核心机制：**鸭鸭说出一个词（声音 + 图案气泡）→ 提示条提醒你带宝宝跟读 → 宝宝发出声音或做出任何操作 → 全屏庆祝「宝宝真棒！」**。没有失败、没有分数，怎么按都有惊喜。

| 操作 | 效果 |
| --- | --- |
| 点水里 | 跳出/游出一只大鸭鸭，有时会当场玩躲猫猫 |
| **点任何一只鸭子** | 它会跳起来、嘎嘎叫或打招呼 |
| 点泡泡 | 泡泡「啪」地破掉，鸭鸭读出里面的词（配图案） |
| 等着看 | 每只鸭子隔几秒自己表演：嘎嘎、跳舞、躲猫猫、飞吻 |
| 🐥 嘎嘎 | 大鸭鸭带两只鸭宝宝一起嘎嘎 |
| 🫧 泡泡 | 升起一串带图案的泡泡 |
| 🎵 唱歌 | 鸭鸭唱 do-re-mi，音符飘起来 |
| 🔢 数鸭鸭 | 五只小鸭鸭带着数字 1-5 排队游过 |
| 🌙 晚安 | 切换白天/夜晚，鸭鸭打瞌睡说晚安 |
| 🎤（右上角） | 开启麦克风：听到宝宝发声自动庆祝 |
| 键盘任意键 | 变出一只带词的鸭鸭（跳/飞/转圈圈/亲亲有专属动作） |
| 空格 / 回车 | 大嘎嘎 / 全部鸭子跳起来 |
| D / B / M / N | 数鸭鸭 / 泡泡 / 唱歌 / 昼夜 |
| 方向键 | ←→ 冲刺，↑ 高飞，↓ 从天而降「扑通！」 |
| 数字 1-5 | 变出对应数量的小鸭鸭一起数数 |

超过 17 秒没人动，大鸭鸭会自己打招呼把宝宝吸引回来。

## 设计依据（为什么这样做）

- **即时因果反馈**：每一次触摸/按键都立刻有动画 + 音效回应
- **躲猫猫的回合结构**（隐藏 → 期待 → 揭晓）：2 岁宝宝最容易理解的互动游戏原型
- **图案 + 声音，不靠文字**：2 岁宝宝不识字，词汇靠听、语义靠图
- **给家长的共玩提示**：提示条持续告诉家长当前该带宝宝说什么（研究表明 App 教家长「扩句、共同注意」比直接教孩子更有效）

参考：[Baby Peekaboo 类因果游戏](https://apps.apple.com)、[Fantasia et al. 2014 躲猫猫互动研究](https://www.frontiersin.org)、[幼儿屏幕学习的「视频赤字」与共玩建议](https://childrenandscreens.org)、[App 支持早期语言发展的研究综述](https://www.researchgate.net)。

## 家长引导建议

- 全程陪同，鸭鸭说一个词就跟宝宝**面对面慢速说一遍**，配合夸张表情和拍手（屏幕学得慢，跟真人学得快）
- 宝宝任何发声（哪怕只是「啊」）都立刻表扬，游戏会自动庆祝配合你
- 一次 10 分钟左右就够；2 岁宝宝建议避免单独、长时间看屏幕
- 右上角 🔊 可一键静音（午睡时间很有用）

## 自定义

用文本编辑器打开 `index.html` 即可改：

- **词表**：`WORDS`（鸭鸭说的词）、`BUBBLE_WORDS`（泡泡里的词）、`PRAISES`（表扬语）
- **图案对照**：`EMOJI`（每个词对应的图画；没有图案的词会直接显示文字）
- **音量**：`master.gain.value`
- **池塘高度**：CSS 里 `#pond { height: 42% }` 和 JS 里 `surfaceY = () => H * 0.58`（两处保持一致）
